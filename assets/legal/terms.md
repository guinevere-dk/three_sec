1. 목적

본 이용약관은 dksoft가 제공하는 모바일 애플리케이션 MOA의 이용 조건과 사용자 및 운영자의 권리, 의무를 정합니다.

2. 서비스

MOA는 사용자가 짧은 Clip을 촬영하거나 가져와 Library에서 관리하고, Vlog 형태로 편집하거나 내보낼 수 있는 모바일 서비스입니다.

서비스는 다음 기능을 포함할 수 있습니다.

- 2초 Clip 촬영 및 기기 내 Library 관리
- 외부 미디어 가져오기
- Vlog 자동 구성 및 내보내기
- Standard 구독자를 위한 편집, Project 저장, Cloud 백업 및 복원
- 알림, 업데이트 안내, 구독 상태 확인, 계정 관리

세부 기능은 앱 버전, 구독 상태, 기기 권한, 네트워크 상태, 스토어 정책에 따라 달라질 수 있습니다.

3. 이용 등급

Free 사용자는 선택한 Clip을 quick 720p로 내보낼 수 있습니다. Free 상태에서는 편집화면 접근, Project 저장, Cloud 저장 기능이 제공되지 않습니다.

Standard 사용자는 편집 기능, Project 저장, Cloud 백업 및 복원 기능을 사용할 수 있습니다. Standard 내보내기 품질은 720p와 1080p를 지원하며 기본값은 1080p입니다. 4K 등 현재 제공하지 않는 품질은 지원되는 최고 품질로 제한될 수 있습니다.

앱은 향후 추가 유료 등급을 제공할 수 있으며, 각 등급의 기능과 가격은 구매 화면과 스토어 결제창에 표시됩니다.

4. Standard 구독과 결제

- Standard 구독 결제는 Google Play 또는 Apple App Store의 인앱결제 시스템을 통해 처리됩니다.
- 구독 상품명, 가격, 기간, 할인 여부는 앱 내 구매 화면과 스토어 결제창에 표시됩니다.
- 구독은 사용자가 스토어에서 해지하기 전까지 자동 갱신될 수 있습니다.
- 사용자가 구독을 해지하더라도 스토어가 표시하는 만료일까지 Standard 기능을 사용할 수 있습니다.
- 환불, 결제 취소, 청구 이의제기, 결제수단 관리는 각 스토어 정책과 계정 설정을 따릅니다.
- 첫 구독 할인, 출시 기념 할인, 프로모션 가격은 사용자의 스토어 계정, 국가, 구독 이력, 스토어 정책에 따라 다르게 표시될 수 있습니다.
- 앱 내 표시 가격과 스토어 결제창 표시 가격이 다를 경우, 최종 구매 전 스토어 결제창에 표시되는 조건이 우선합니다.

운영자는 결제 카드번호 등 원 결제수단 정보를 직접 수집하거나 저장하지 않습니다. 구독 권한 확인을 위해 필요한 구매 상태와 거래 메타데이터만 처리할 수 있습니다.

5. Cloud 백업 정책

Standard 사용자는 계정당 50GB Cloud 백업 공간을 사용할 수 있습니다.

Cloud는 무제한 스트리밍 서비스나 원본 영상 영구 보관소가 아닙니다. Cloud에는 MOA 서비스 이용에 맞게 처리된 영상과 Project 정보가 백업될 수 있으며, 안정적인 백업과 복원을 위한 용도로 제공됩니다.

운영자는 서비스 안정성, 비용 통제, 악용 방지를 위해 단일 파일 크기, 업로드 빈도, 다운로드 사용량, 캐시 사용, 복원 방식을 제한할 수 있습니다.

구독이 만료되거나 Free로 전환되면 신규 Cloud 업로드와 Cloud 저장은 제한됩니다. 기존 Cloud 데이터에 대해서는 운영 정책에 따라 제한된 유예기간 동안 다운로드 또는 복원 기능이 제공될 수 있으며, 현재 기준 유예기간은 30일입니다.

6. 캐시와 로컬 파일

앱은 편집, 미리보기, 내보내기, Cloud 복원 과정에서 임시 캐시 파일을 생성할 수 있습니다. 이러한 캐시는 일정 기간 후 자동 삭제될 수 있습니다.

캐시 삭제는 Cloud 백업 삭제와 다릅니다. 캐시를 지워도 Cloud에 백업된 데이터가 곧바로 삭제되는 것은 아니며, Cloud 데이터 삭제는 앱의 삭제 기능 또는 계정 삭제 절차를 따릅니다.

내보낸 영상, 기기 갤러리에 저장된 파일, 다른 앱으로 공유한 파일, 사용자가 기기에 보관한 원본 파일은 사용자가 직접 관리해야 합니다.

7. 계정과 삭제

사용자는 Google, Apple, Kakao, Naver 등 지원되는 로그인 방식을 통해 계정을 생성하거나 로그인할 수 있습니다. Guest 모드에서는 계정 기반 Cloud, 구독, 동기화 기능이 제한됩니다.

사용자는 앱 내 계정 관리 기능 또는 운영자가 고지한 문의 채널을 통해 계정 삭제를 요청할 수 있습니다. 계정 삭제 시 운영자는 관련 법령과 기술적 한계 내에서 계정 정보, Cloud Clip, Project, Cloud 저장 파일 등 운영자가 관리하는 사용자 데이터를 삭제하거나 삭제 예약합니다.

다만 사용자의 기기에 남아 있는 로컬 파일, 갤러리에 저장된 파일, 다른 앱으로 공유한 파일, 스토어가 보관하는 결제 기록은 별도로 삭제되지 않을 수 있습니다.

8. 사용자 콘텐츠

사용자가 촬영, 가져오기, 업로드, 편집, 내보내기 한 콘텐츠의 권리는 원칙적으로 사용자에게 있습니다.

사용자는 본인이 사용하는 영상, 이미지, 음성, 음악, 인물, 장소, 상표, 저작물에 대해 필요한 권리와 동의를 확보해야 합니다. 불법 촬영물, 타인의 권리를 침해하는 콘텐츠, 음란물, 혐오 또는 폭력 조장 콘텐츠, 범죄 또는 불법 행위를 조장하는 콘텐츠를 서비스에 저장하거나 공유해서는 안 됩니다.

운영자는 서비스 제공, 백업, 복원, 미리보기, 편집, 내보내기, 오류 복구, 보안 점검에 필요한 범위에서 사용자 콘텐츠를 저장, 처리, 전송, 캐시할 수 있습니다.

9. 이용 제한

운영자는 다음 사유가 있는 경우 서비스 이용을 제한하거나 필요한 조치를 할 수 있습니다.

- 법령 또는 본 약관 위반
- 타인의 권리, 개인정보, 초상권, 저작권 침해
- 결제 부정 사용, 구독 상태 조작, 권한 우회
- Cloud 저장공간, 업로드, 다운로드 기능의 비정상적 또는 과도한 사용
- 서비스 장애, 보안 위험, 데이터 손상 위험을 유발하는 행위
- 비인가 자동화, 우회 접근, 리버스 엔지니어링 등 서비스 보호를 해치는 행위

10. 서비스 변경과 중단

운영자는 기능 개선, 보안 패치, 정책 변경, 스토어 정책 변경, 외부 서비스 장애, 운영상 필요에 따라 서비스 일부를 변경하거나 중단할 수 있습니다.

장기간 서비스 종료 또는 사용자 데이터에 중대한 영향을 주는 변경이 있는 경우 운영자는 가능한 범위에서 사전 고지합니다.

11. 책임 제한

운영자는 관련 법령상 허용되는 범위 내에서 서비스 중단, 오류, 데이터 동기화 지연, 기기 저장공간 부족, 네트워크 장애, 스토어 결제 장애, 외부 서비스 장애로 인한 손해에 대해 책임을 제한할 수 있습니다.

운영자의 고의 또는 중대한 과실이 있거나 법령상 책임을 제한할 수 없는 경우에는 본 제한이 적용되지 않습니다.
